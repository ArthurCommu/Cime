# Tickets — signalements sur Cime venus d'ailleurs

L'utilisateur dépose ici les tickets à traiter par l'Assistant : un défaut ou une friction de Cime
constaté dans un autre projet lancé avec Cime (rédigé par l'Assistant de ce projet), ou ailleurs.

- Un fichier par ticket, en Markdown : `<date>-<sujet-court>.md` (le nom d'origine convient aussi).
- L'Assistant lit le ticket, répond à l'utilisateur, puis note la suite en tête du fichier
  (`Suite : …` — chantier, équipe, commit, ou « sans suite » et pourquoi).
- Un ticket traité reste ici : c'est l'historique.
